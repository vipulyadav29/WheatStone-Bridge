# WheatStone Bridge Presentation Notes

## 1. Introduction
WheatStone Bridge is an AI-driven wheat leaf disease detection web application created as a final year project.

## 2. Problem
Manual disease identification is slow and depends on expert knowledge. Early diagnosis is important for reducing crop loss.

## 3. Solution
The user uploads a wheat leaf image, the system analyses it, predicts the likely disease class, and shows guidance.

## 4. Technologies
- Flask
- Python
- HTML/CSS/JavaScript
- SQLite
- Machine Learning

## 5. Output Classes
- Healthy
- Rust
- Leaf Blight
- Powdery Mildew

## 6. Key Benefit
The project combines a real web app, ML prediction, and project presentation quality in one platform.
